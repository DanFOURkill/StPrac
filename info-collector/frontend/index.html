InfoCollector

Учебная информационная система для сбора данных с веб-страниц.

О системе

InfoCollector помогает пользователю собрать текстовую информацию с выбранной веб-страницы по заданному поисковому запросу.

  • Назначение: быстро найти полезные фрагменты текста на странице и сохранить результат для учебного анализа.
  • Собираемые данные: дата сбора, URL источника, заголовок страницы, найденные абзацы и количество ссылок.
  • Работа пользователя: пользователь вводит запрос и URL, нажимает кнопку сбора, смотрит результат, историю, экспортирует CSV или удаляет записи.
  • Хранение: результаты сохраняются локально в базе данных SQLite в папке data.
  • Ограничения парсинга: некоторые сайты блокируют автоматические запросы, требуют JavaScript или отдают неполный HTML.
