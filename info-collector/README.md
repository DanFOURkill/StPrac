# InfoCollector

InfoCollector — учебное веб-приложение для сбора определённой пользователем информации из сети Интернет.

## Возможности

- форма для ввода поискового запроса и URL сайта;
- загрузка HTML-страницы через `requests`;
- разбор HTML с помощью `BeautifulSoup4`;
- извлечение заголовка страницы, абзацев и ссылок;
- фильтрация абзацев по поисковому запросу;
- сохранение результатов в SQLite;
- просмотр истории запросов;
- удаление записей из истории;
- экспорт результатов в CSV.

## Инструкция запуска

Все команды ниже выполняются из корневой папки репозитория `/workspace/StPrac`, если не указано иначе.

### 1. Создать виртуальное окружение

Перейдите в папку учебного проекта:

```bash
cd info-collector
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте окружение в Linux/macOS:

```bash
source .venv/bin/activate
```

Активируйте окружение в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

После активации в начале строки терминала обычно появляется `(.venv)`.

### 2. Установить зависимости

Установите зависимости backend из файла `requirements.txt`:

```bash
python -m pip install -r backend/requirements.txt
```

Если установка прошла успешно, в окружении будут доступны `FastAPI`, `uvicorn`, `requests` и `BeautifulSoup4`.

### 3. Запустить FastAPI backend

Запустите сервер из папки `info-collector`:

```bash
python -m uvicorn backend.main:app --reload
```

Backend будет доступен по адресу:

```text
http://127.0.0.1:8000
```

Проверить, что backend запустился, можно в браузере по адресу:

```text
http://127.0.0.1:8000/docs
```

### 4. Открыть frontend

Оставьте FastAPI запущенным и откройте второй терминал.

Перейдите в папку frontend:

```bash
cd info-collector/frontend
```

Запустите простой локальный сервер для статических файлов:

```bash
python -m http.server 8080
```

Откройте приложение в браузере:

```text
http://127.0.0.1:8080
```

Также можно открыть файл `frontend/index.html` напрямую, но запуск через `python -m http.server 8080` надёжнее для локальной проверки.

### 5. Примеры URL для проверки

Для проверки можно использовать простые публичные страницы:

| URL | Пример поискового запроса | Что проверить |
| --- | --- | --- |
| `https://example.com` | `domain` | Должен найти абзац про example domain и посчитать ссылки. |
| `https://www.iana.org/domains/reserved` | `reserved` | Должен собрать абзацы со страницы IANA. |
| `https://www.python.org/` | `Python` | Должен получить заголовок страницы и найденные фрагменты. |

Порядок проверки:

1. Введите поисковый запрос.
2. Введите один из URL выше.
3. Нажмите кнопку «Собрать информацию».
4. Проверьте блок «Результаты».
5. Проверьте, что запись появилась в «Истории запросов».
6. Нажмите «Экспорт в CSV», чтобы скачать историю.
7. Нажмите «Удалить» у записи в истории, чтобы проверить удаление.

## Возможные ошибки запуска

- Если команда `python -m uvicorn backend.main:app --reload` не запускается, проверьте, что виртуальное окружение активировано и зависимости установлены.
- Если frontend показывает ошибку запроса, проверьте, что FastAPI работает на `http://127.0.0.1:8000`.
- Если выбранный сайт не отдаёт данные, попробуйте другой URL из примеров: некоторые сайты блокируют автоматические запросы.
- Если порт `8000` или `8080` занят, остановите приложение, которое использует порт, или выберите другой порт.

## Примечания

- База данных создаётся автоматически в папке `data`.
- Некоторые сайты могут блокировать автоматические запросы или отдавать неполный HTML.
- Проект предназначен для учебной практики и специально написан простым кодом с комментариями.
