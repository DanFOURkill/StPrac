# Тестовые данные

Для проверки системы используйте собственные изображения и короткие видео:

- фотографии аудиторий, учебных классов и рабочих пространств;
- снимки парт и столов, на которых лежит один ноутбук;
- изображения с несколькими ноутбуками на разных рабочих местах;
- изображения без ноутбуков для проверки ложных срабатываний;
- кадры с частично закрытыми ноутбуками и разным освещением для оценки ограничений модели.

Файлы можно загрузить через веб-интерфейс после запуска приложения.
