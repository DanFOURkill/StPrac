# Система детекции ноутбуков на партах

Учебный проект по дисциплине «Системы искусственного интеллекта»: локальное веб-приложение для поиска ноутбуков на изображениях и видео аудиторий, классов и рабочих пространств.

## Цель проекта

Разработать демонстрационную AI-систему компьютерного зрения, которая применяет предобученную нейронную сеть для решения задачи object detection и показывает результат в понятном веб-интерфейсе.

## Описание задачи

Пользователь загружает фото или видео помещения, где на партах могут находиться ноутбуки. Система:

1. считывает файл через OpenCV;
2. запускает предобученную YOLOv8;
3. оставляет только detections класса `laptop`;
4. рисует bounding boxes и подписи «Ноутбук» с confidence;
5. сохраняет результат в `static/results`;
6. показывает статистику и записывает запрос в SQLite-историю;
7. позволяет выгрузить историю в Excel или PDF.

## Используемые технологии

- Python 3.10+
- Flask
- ultralytics YOLOv8
- OpenCV
- SQLite
- HTML/CSS/JavaScript
- pandas и openpyxl для Excel-отчёта
- reportlab для PDF-отчёта

## Почему выбрана YOLOv8

YOLOv8 хорошо подходит для учебного проекта, потому что это современная и простая в использовании модель детекции объектов. Библиотека `ultralytics` позволяет быстро подключить предобученные веса `yolov8n.pt`, выполнить инференс на изображениях и кадрах видео, отфильтровать нужные классы и получить координаты bounding boxes. В проекте используется лёгкая версия YOLOv8n, чтобы приложение могло запускаться локально на обычном компьютере.

## Установка зависимостей

```bash
cd laptop-desk-detector
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

При первом запуске модель `yolov8n.pt` может быть автоматически скачана библиотекой `ultralytics`.

## Запуск проекта

```bash
python app.py
```

После запуска откройте в браузере адрес:

```text
http://127.0.0.1:5000
```

## Как пользоваться веб-приложением

1. Откройте главную страницу.
2. Выберите изображение или видео аудитории/стола/рабочего места.
3. Установите confidence threshold, например `0.35`.
4. Нажмите «Запустить обработку».
5. Дождитесь завершения обработки.
6. Просмотрите изображение или видео с рамками вокруг найденных ноутбуков.
7. Проверьте статистику и таблицу истории.
8. При необходимости скачайте Excel- или PDF-отчёт.

## Что сохраняется в истории

SQLite-база `history.db` создаётся автоматически при первом запуске приложения. В ней создаётся таблица `requests` со следующими полями:

- `id` — идентификатор записи;
- `timestamp` — дата и время обработки;
- `filename` — имя исходного файла;
- `file_type` — тип файла: `image` или `video`;
- `laptops_count` — количество ноутбуков на изображении;
- `avg_laptops_count` — среднее количество ноутбуков по кадрам видео;
- `max_laptops_count` — максимальное количество ноутбуков в одном кадре;
- `confidence_threshold` — выбранный порог уверенности;
- `result_path` — путь к обработанному файлу;
- `processing_time_seconds` — время обработки в секундах.

## Как формируются отчёты

- Endpoint `/export/excel` берёт историю из SQLite и сохраняет таблицу в `reports/history_report.xlsx`.
- Endpoint `/export/pdf` формирует PDF-таблицу `reports/history_report.pdf` через `reportlab`.
- В отчёты попадают все записи истории, а не только последние строки, показанные на главной странице.

## Возможные ограничения

- Модель может ошибаться при плохом освещении.
- Закрытые или частично видимые ноутбуки могут не распознаваться.
- Похожие объекты могут давать ложные срабатывания.
- Для длинных видео обработка может занимать заметное время, особенно без GPU.
- Предобученная модель COCO не адаптирована специально под конкретную аудиторию или ракурс камеры.

## API

### `POST /process`

Параметры формы:

- `file` — изображение или видео;
- `confidence` — порог confidence от `0.01` до `0.99`.

Ответ для изображения содержит количество ноутбуков, список confidence, путь к результату, дату и время обработки.

Ответ для видео содержит путь к результату, среднее количество ноутбуков по кадрам, максимум в кадре, число обработанных кадров, дату и время обработки.

### `GET /history`

Возвращает JSON со всей историей запросов.

### `GET /export/excel`

Скачивает Excel-отчёт.

### `GET /export/pdf`

Скачивает PDF-отчёт.
